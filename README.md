# Python Task 02 — Decision Making & Logic Building

## Cyber Security Summer Internship

This repository contains solutions for **Task 02 – Conditional Statements & Logical Thinking** completed as part of the **Cyber Security Summer Internship**.

The project demonstrates the use of Python decision-making constructs such as:

* `if`, `elif`, and `else`
* Comparison operators
* Logical operators (`and`, `or`)
* Input validation
* Exception handling (`try/except`)
* String analysis and validation

### Programs Included

| File                  | Description                                   |
| --------------------- | --------------------------------------------- |
| `even_odd.py`         | Determines whether a number is even or odd    |
| `largest_number.py`   | Finds the largest among three numbers         |
| `grade_calculator.py` | Calculates grades based on marks              |
| `login_validation.py` | Validates username and password credentials   |
| `password_checker.py` | Checks password strength using security rules |

### Learning Outcomes

✔ Understanding conditional statements
✔ Implementing logical decision-making
✔ Handling user input safely
✔ Building simple authentication systems
✔ Applying password security concepts

### Cyber Security Relevance

This task introduces foundational concepts used in cybersecurity applications:

* Authentication and Login Validation
* Password Policy Enforcement
* Input Validation
* Security-Oriented Programming Logic
